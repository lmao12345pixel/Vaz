# Screenshots Gallery & Lightbox Viewer Contract

Contract quy định hành vi giao diện cho tính năng Screenshots Gallery & Lightbox Viewer trên Web Prototype (`docs/design-preview/`), dùng làm executable specification trước khi port sang WinUI 3 desktop.
