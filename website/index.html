Diagnostics & Crash Analyzer

Tự động phân tích stacktrace và crash report bằng thuật toán chẩn đoán thông minh. Chỉ trong 0.2 giây, launcher chỉ rõ mod gây lỗi, thiếu dependencies hay không tương thích phiên bản Java.

Tích hợp đồng thời cả Modrinth và CurseForge API. Dễ dàng tìm kiếm hàng nghìn mod, gói tài nguyên, shaders và datapacks với khả năng tự động giải quyết dependencies chỉ trong 1 cú nhấp chuột.

Emerald Play Dock — Bảng Điều Khiển Nhanh

Không cần mở nhiều cửa sổ rườm rà. Bảng điều khiển tích hợp cho phép bạn chọn instance, theo dõi dung lượng RAM thực tế, mở thư mục game hoặc khởi chạy với một cú nhấp chuột.

  • ✔ Quản lý độc lập thư mục game cho từng instance (không bị trộn lẫn mods).
  • ✔ Tự động phát hiện và cấu hình đường dẫn Java runtime tối ưu nhất.
  • ✔ Kill switch khẩn cấp tắt nhanh game khi bị treo hoặc out of memory.

Visual options.txt Editor — Chỉnh Cấu Hình Ngoài Game

Không còn cảnh phải khởi động game chỉ để hạ cấu hình khi bị giật lag. V.A.Z cho phép chỉnh sửa trực quan file options.txt với các thanh trượt an toàn, bảo vệ chống crash do đặt nhầm giá trị.

  • ✔ Tùy biến FOV, Render Distance, GUI Scale ngay trên Launcher.
  • ✔ Chế độ Gamma sáng tối (Fullbright) an toàn mà không cần cài thêm mod.
  • ✔ Tự động sao lưu bản cấu hình trước khi lưu thay đổi mới.

Importer Wizard — Chuyển Đổi Dữ Liệu Dễ Dàng

Bạn đang dùng Prism Launcher, CurseForge hay Modrinth App? Trình hướng dẫn thông minh sẽ tự động nhập toàn bộ thư mục thế giới, mods và cấu hình chỉ với một thao tác kéo thả.

  • ✔ Hỗ trợ định dạng .mrpack, .zip, và modpack CurseForge.
  • ✔ Tự động quét và phát hiện các launcher đã cài trên máy tính.
  • ✔ Giữ nguyên 100% keybinds, thành tựu (advancements) và file save.

Câu Hỏi Thường Gặp (FAQ)

Những điều bạn cần biết trước khi bắt đầu hành trình cùng V.A.Z Launcher.

Hoàn toàn an toàn. V.A.Z Launcher sử dụng luồng xác thực chuẩn OAuth 2.0 trực tiếp từ máy chủ Microsoft và Xbox Live. Mật khẩu của bạn không bao giờ đi qua bất kỳ máy chủ trung gian nào. Mã nguồn mở 100% trên GitHub cho phép cộng đồng kiểm tra minh bạch.

Khác với các launcher xây dựng trên Electron (vốn phải đóng gói cả trình duyệt Chromium và Node.js nặng hàng trăm MB), V.A.Z được viết thuần bằng ngôn ngữ C# trên nền tảng .NET 8 và giao diện WinUI 3 bản địa của Windows. Điều này giúp launcher đạt hiệu năng tối đa và tiêu thụ RAM chỉ khoảng ~35 MB khi chạy nền.

Có. Bạn chỉ cần dùng tính năng Importer Wizard có sẵn, kéo thả tệp .mrpack, .zip hoặc chỉ định thư mục instance cũ. V.A.Z sẽ giữ nguyên toàn bộ mods, saves, options và keybinds mà không làm mất dữ liệu.

Không nhất thiết. Launcher tích hợp bộ phân giải Java tự động (Java Resolver), có thể tự động tải và cấu hình phiên bản Java phù hợp (Java 8, 17, hoặc 21 LTS) tương ứng với từng phiên bản Minecraft mà bạn khởi chạy.

V.A.Z hỗ trợ đầy đủ mọi Mod Loader hiện đại: Fabric, NeoForge, Minecraft Forge, Quilt và OptiFine, với khả năng tự động cập nhật phiên bản loader mới nhất chỉ bằng 1 cú nhấp chuột.
